# 전체 데이터 수동 업데이트 눌러도 갱신중 바가 나오지 않는 경우

## 원인

- 네트워크 연결 실패
- 매니저 꺼짐
- 앱 내부 이슈

## 처리방법 요약

아래 순서대로 진행하고, 각 단계 후 전체 데이터 수동 업데이트를 눌러 갱신중 바가 나오는지 확인한다. 해결되면 중단.

1. **기기 재부팅**
   - 기기를 재부팅한 뒤 확인한다.
2. **전체 데이터 수동 업데이트 터치 후 돌아가기**
   - 전체 데이터 수동 업데이트를 터치한다.
   - 이전 화면으로 돌아가서 확인한다.
3. **한눈에 조직도 종료 후 재진입**
   - 한눈에 조직도 앱을 종료한다.
   - 좌측 하단 아이콘을 터치해 다시 진입한 뒤 확인한다.
4. **KIOSK_VERSION 파일 확인**
   - 익스플로러에서 `KIOSKData/KIOSK_VERSION` 파일이 있는지 확인한다.

     | 상태 | 조치 |
     |------|------|
     | `KIOSK_VERSION` 있음 | 파일 삭제 → 한눈에 조직도 재실행 |
     | `KIOSK_VERSION` 없음 | 한눈에 조직도 재실행 |

5. **한눈에 조직도 M 데이터 클리어**
   - 한눈에 조직도 M의 데이터를 클리어한다.
   - 한눈에 조직도를 재실행하고 설정을 다시 진행한 뒤 확인한다.

6. **서버 데이터 확인**
   - json/getTeams 데이터 이상 있는지 확인한다.
   - 이상 없는 경우 프로젝트 내부 확인 필요.

## 자세한 내용

각 처리방법을 하는 이유.

1. **기기 재부팅**
   - 네트워크 재연결, 매니저 재실행, 꼬인 로직을 한 번에 해결한다.
2. **전체 데이터 수동 업데이트 터치 후 돌아가기**
   - 1번으로 원인이 해결되어도 기존 KIOSK_VERSION 이 남아있으면 갱신되지 않으므로 이를 해결한다.
3. **한눈에 조직도 종료 후 재진입**
   - 매니저를 재실행한다.
4. **KIOSK_VERSION 파일 확인**
   - 매니저가 꺼져있어 KIOSK_VERSION 파일이 삭제되지 않은 경우를 해결한다.
5. **한눈에 조직도 M 데이터 클리어**
   - 부서코드가 선택되지 않는 문제를 해결한다.
